# Superpowers

This skill provides direct access to the Superpowers skill framework.

See full instructions in [using-superpowers](../using-superpowers/SKILL.md).

## The Rule
**Invoke relevant skills BEFORE any response or action.**
If you think there is even a 1% chance a skill applies, invoke it.

## Skill Priority
1. **Process skills first** (`brainstorming`, `systematic-debugging`) — determine HOW to approach the task.
2. **Implementation skills second** (`test-driven-development`, `writing-plans`, `executing-plans`) — guide execution.
3. **Completion skills** (`verification-before-completion`, `finishing-a-development-branch`) — verify before done.
